# Collectors

{% hint style="warning" %}
🛠️ **Planned** — Collectors are not implemented in version `0.1.0-SNAPSHOT`. This page only lists the official rules they will follow. Capacity, placement and usage will be documented here when the feature is released.
{% endhint %}

## Official rules

| Rule | Description |
|---|---|
| 📦 **Money storage** | Collectors store the money produced by spawners. |
| 🦝 **Collectors can be stolen** | A collector, and the money inside it, can be stolen by another player. |
