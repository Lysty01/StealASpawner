# Feature Status

**Current version:** `0.1.0-SNAPSHOT` (development, phase 1.2)

## Available

| Feature | Status | Since | Documentation |
|---|---|---|---|
| Plugin loads, enables and disables cleanly on Paper 1.21.11 | ✅ Available | 0.1.0 | [Installation](installation.md) |
| Optional load order with LuckPerms and Oraxen (`softdepend`) | ✅ Available | 0.1.0 | [Administration](../administration/README.md) |
| YAML configuration files, created on first start and strictly validated | ✅ Available | 0.1.0 (phase 1.2) | [Configuration](../administration/configuration.md) |
| Customizable messages (MiniMessage, configurable prefix) | ✅ Available | 0.1.0 (phase 1.2) | [Messages](../administration/messages.md) |
| Safe configuration reload with `/sas reload` | ✅ Available | 0.1.0 (phase 1.2) | [/sas reload](../commands/sas-reload.md) |
| Permission `stealaspawner.admin.reload` | ✅ Available | 0.1.0 (phase 1.2) | [Permissions & Ranks](../permissions/README.md) |
