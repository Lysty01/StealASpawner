# Raiding

{% hint style="warning" %}
🛠️ **Planned** — Raiding is not implemented in version `0.1.0-SNAPSHOT`. This page only lists the official rules it will follow. How to start a raid, protections and cooldowns will be documented here when the feature is released.
{% endhint %}

## What can be stolen

| Target | Rule |
|---|---|
| 💰 **Money** | Up to **100%** of a player's unprotected money. |
| 📦 **Collectors** | Collectors and the money inside them. |
| 🏭 **Spawners** | Spawners keep their **level and upgrades** after being stolen. |
