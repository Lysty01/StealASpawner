# Economy

{% hint style="warning" %}
🛠️ **Planned** — The economy is not implemented in version `0.1.0-SNAPSHOT`. This page only lists the official rules it will follow. Prices, rates and commands will be documented here when the feature is released.
{% endhint %}

## Official rules

| Rule | Description |
|---|---|
| ♾️ **Unlimited offline production** | Spawners keep producing money while their owner is offline. There is no cap on duration or amount. |
| 💰 **All money can be stolen** | Up to **100%** of a player's unprotected money can be taken by raiders. No share is protected by default. |
