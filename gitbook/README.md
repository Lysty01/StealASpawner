# Steal a Spawner — Official Wiki

**Build your spawner empire. Protect your base. Steal everything from everyone else.**

Steal a Spawner is a multiplayer Minecraft minigame for **Paper 1.21.11** servers. Every player runs a base full of money-producing spawners, and every base can be raided.

{% hint style="warning" %}
**Early development — version `0.1.0-SNAPSHOT`.**
The plugin currently installs, starts and stops cleanly, but **no gameplay feature is available yet**. Pages marked 🛠️ **Planned** describe the official design, not something you can use today. See [Feature Status](getting-started/feature-status.md).
{% endhint %}

## How to read this wiki

### Feature status

| Badge | Meaning |
|---|---|
| ✅ **Available** | Implemented in the current version and usable on your server |
| 🛠️ **Planned** | Part of the official design, not implemented yet |

### Audience

Commands, permissions and mechanics are tagged with the type of player they are meant for:

| Tag | Audience |
|---|---|
| 🟢 **Player** | Every player on the server |
| 🟣 **Premium** | Players with a premium rank (VIP, supporter…) |
| 🔴 **Admin** | Staff and server administrators |
