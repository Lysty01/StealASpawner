# Spawners

{% hint style="warning" %}
🛠️ **Planned** — Spawners are not implemented in version `0.1.0-SNAPSHOT`. This page only lists the official rules they will follow. Spawner types, levels, upgrade costs and production rates will be documented here when the feature is released.
{% endhint %}

## Official rules

| Rule | Description |
|---|---|
| 🏭 **Money production** | Spawners placed in a player's base produce money over time. |
| ♾️ **Offline production** | Production continues while the owner is offline, with no limit. |
| ⬆️ **Levels are kept when stolen** | A stolen spawner keeps its level and upgrades for its new owner. |
